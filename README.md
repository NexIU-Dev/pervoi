# PerVoí

Landing page da PerVoí, feita em Astro. Apresenta loiros, mega hair e os demais cuidados do salão, com trabalhos publicados no perfil oficial e contato pelo WhatsApp.

## Desenvolvimento

```bash
npm ci
npm run dev
```

Para conferir a versão estática:

```bash
npm run check
npm run build
npm run preview
```

Com a configuração atual, a página local fica no caminho `/pervoi/`. O deploy no GitHub Pages é executado pelo workflow em `.github/workflows/deploy.yml` a cada push na branch `main`.
